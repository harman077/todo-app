# 📝 To-Do App

## 📖 Description
A simple and responsive **To-Do App** built with **React** and **Vite**.  
This app allows users to **add, edit, delete, and mark tasks as complete**, helping them stay productive and organized.  

It’s designed as a **frontend portfolio project** to demonstrate React hooks, component structure, and state management.

---

## 🚀 Features
- ✨ Add new tasks  
- 🗑️ Delete tasks  
- ✅ Mark tasks as completed  
- 🖋️ Edit existing tasks  
- 💾 Data persistence using local storage  
- 📱 Responsive design (mobile-friendly)  
- ⚡ Built with React + Vite for fast development  

---

## 🧩 Tech Stack
- **Frontend:** React, Vite  
- **Styling:** CSS / Bootstrap 
- **State Management:** React Hooks (`useState`, `useEffect`)  
- **Deployment:** GitHub Pages / Netlify  

---

## ⚙️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/harman077/todo-app.git
   cd todo-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. Open in browser:  
   👉 `http://localhost:5173`
